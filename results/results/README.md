# Model Evaluation Results

This folder contains the evaluation results of the
CIFAR-10 Deep CNN image classification project.

## Final Performance

- Test Accuracy: 86.38%
- Test Loss: 0.4196
- Test Images: 10,000
- Number of Classes: 10

- Confusion Matrix
- Training and Validation Accuracy Graph

- Classification Report
